#  FarmCycle – Agricultural Waste Management System

FarmCycle is a console-based application developed in **C** that promotes the efficient reuse of agricultural waste by connecting farmers with potential buyers. Instead of discarding agricultural waste, farmers can list waste materials that can be utilized by industries to produce useful products.

##  Objective

To reduce agricultural waste and encourage its reuse by providing a platform where farmers can list waste materials and buyers can explore and purchase them.

## Features

- 👨‍🌾 Farmer registration
- 🆔 Automatic Farmer ID generation
- 🌾 Listing agricultural waste materials
- 🔍 Browsing available waste
- 🛒 Purchasing waste from farmers
- ♻️ Finding alternative resources
- 📱 Phone number validation
- 📋 Menu-driven interface

## 🛠️ Technologies Used

- **Language:** C
- **Concepts:** Data Structures and Algorithms
- **Platform:** Console-based application

## 💡 How It Works

1. Farmers register themselves on the platform.
2. They add agricultural waste materials available for sale.
3. Buyers browse the available materials.
4. Buyers select materials from farmers using the Farmer ID.
5. The system facilitates the reuse of agricultural waste.

## 🌍 Impact

FarmCycle aims to:

- Reduce agricultural waste disposal.
- Encourage sustainable resource utilization.
- Connect farmers with industries that reuse agricultural waste.
- Promote a circular economy in agriculture.
